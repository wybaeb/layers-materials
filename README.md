# LAYERS × KARPOV.COURSES — материалы курса

Содержимое страниц зашифровано (AES-256-GCM, ключ выводится из пароля через
PBKDF2-SHA256, 310 000 итераций). Пароль спрашивается в браузере при первом
открытии, сохраняется в cookie на год и никуда не отправляется — расшифровка
происходит целиком на стороне читателя.

Картинки лежат открыто: без текста они ничего не раскрывают, зато открываются
напрямую и не утяжеляют каждую страницу.

Пароля в этом репозитории нет. Источники и сборка — в приватном
`wybaeb/layers-workspace` (`layers_course/pipeline/publish_pages.py`).

Открыть: https://wybaeb.github.io/layers-materials/
